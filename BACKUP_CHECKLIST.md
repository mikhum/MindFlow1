# Backup Checklist — MindFlow1

**Repository:** `mikhum/MindFlow1`  
**Last Updated:** July 9, 2026

## 1) Goal

Ensure mind map data is consistently recoverable from Google Drive backups.

---

## 2) Backup Scope

- [ ] Active mind map files
